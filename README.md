Online Food Ordering System (OOP Project)
Project Overview
This project is an Online Food Ordering System developed using Object-Oriented Programming (OOP) concepts in C++.
The system simulates how customers can browse a menu, place orders, select delivery addresses, make payments, and give reviews.
The project focuses on real-world problem modeling using classes, objects, and relationships between them.

Objectives
Apply core OOP concepts in a practical system
Understand class interaction in a real-world application
Implement modular and reusable code
Simulate a basic food ordering workflow

OOP Concepts Used
Classes & Objects
Encapsulation
Constructors & Destructors
Aggregation & Composition
Arrays of Objects
File-based project structure
Separation of concerns
